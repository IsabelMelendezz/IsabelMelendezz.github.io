Proyecto 01

Sistema de Reparto

Proyecto 02

Supermercado — Ventas y Cuentas por Cobrar

Sistema de gestión de ventas y cuentas por cobrar desarrollado en Java con NetBeans, diseñado para administrar el ciclo completo de cotizaciones, ventas, validación de pagos, actualización de inventario y emisión de facturas. Incorpora operaciones CRUD, procesos transaccionales, generación de reportes con JasperReports, bitácora de acciones y validaciones de negocio, con integración a base de datos mediante JDBC bajo una arquitectura por capas.

Proyecto 03

Infraestructura Virtualizada y Ciberseguridad Empresarial

Arquitectura de red segmentada con DMZ, red interna y servidor bastión con firewall iptables, virtualizada sobre VirtualBox con Ubuntu Server. Incluye análisis de riesgos con metodología MAGERIT sobre más de 50 activos, alineado a controles ISO/IEC 27001:2013, replicación Master-Master en MySQL, proxy inverso Nginx, proxy Squid y VPN para acceso remoto seguro.
